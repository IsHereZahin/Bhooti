<h1 align="center">Bhooti</h1>

<p align="center">A quiet, living notch at the top of your Windows screen.</p>

Bhooti turns the top edge of your screen into a small notch that stays out of
your way until something is worth showing: the song that's playing, the minutes
left in a focus session, a reminder to drink water. Rest the pointer on it, or
press **Ctrl + Alt + Space**, and it opens.

It's a native Windows app that draws only while something changes and uses no
CPU when idle.

## What It Does

| Feature | What it does |
| --- | --- |
| **Music** | What's playing in any app that shares it with Windows (Spotify, browsers, Apple Music, Media Player), with artwork, progress and playback controls |
| **Lyrics** | Synced lyrics that follow the song; click a line to jump to it |
| **Focus** | A Pomodoro timer with breaks, a chime and daily statistics |
| **To-do** | Quick add, like `Call mom #home !high @tomorrow-9am`, with due times, reminders and snooze |
| **Drink** | A daily water goal, an hourly chart and reminders that skip while you keep pace |
| **Screen Time** | Optional: your time at the PC today, and a short break after a long stretch |
| **Shelf** | Drop files or text on the notch and drag them back out later; files are never copied |
| **Clipboard** | What you copied in the last 2 days, one click to copy it again; text that password managers mark private is never saved |
| **System** | Brief indicators for volume, brightness, charging, battery, headphones, Caps Lock and input language |

It follows your light or dark theme and accent colour, can start with Windows,
and hides in fullscreen apps.

## Requirements

Windows 10 (version 1809 or newer) or Windows 11, on a 64-bit (x64) PC.

## Install

Get the latest version from [Releases](https://github.com/IsHereZahin/Bhooti/releases/latest).

## Privacy

Bhooti has no accounts, ads, analytics or telemetry, and everything it keeps
stays on your PC. Its one network request is the optional lyrics lookup, which
sends the song's title, artist, album and length to [LRCLIB](https://lrclib.net);
turn lyrics off in Settings › Music and it makes none. Read the full
[privacy policy](https://isherezahin.github.io/Bhooti/privacy.html).
